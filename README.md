# Thousand — интернет-магазин на Laravel

Учебный пет-проект: интернет-магазин с каталогом, корзиной, оформлением заказа, личным кабинетом и админ-панелью.

## Возможности

**Для покупателя**
- Каталог с категориями и поиском, страница товара
- Корзина: добавление, изменение количества, удаление
- Оформление заказа с проверкой остатков на складе (только для вошедших пользователей)
- Регистрация, вход, восстановление пароля по email
- Профиль: изменение данных, смена пароля, история заказов со статусами
- Адаптивная вёрстка для телефонов

**Для администратора**
- Главная со статистикой: заказы, новые заказы, выручка, закончившиеся товары, последние заказы
- Товары: поиск, добавление, редактирование, загрузка фото, скрытие из каталога, удаление
- Заказы: фильтр по статусу, поиск по имени и телефону, просмотр, смена статуса
- Категории: добавление, переименование, удаление (только пустых)
- Доступ только для пользователей с правами администратора

## Стек

- PHP 8.3+, Laravel 13
- MySQL
- Blade, Tailwind CSS 4, Vite
- Pest — 100+ автотестов

## Запуск локально

Нужны PHP 8.3+ (с расширениями `pdo_mysql`, `gd`, `fileinfo`), Composer, Node.js и MySQL.

```bash
git clone https://github.com/MrDoctor001/pet_project_1.git
cd pet_project_1

# создайте пустую базу pet_project_1 и при необходимости укажите логин и пароль в .env
composer run setup
php artisan db:seed

composer run dev
```

Сайт откроется на [http://localhost:8000](http://localhost:8000).

`php artisan db:seed` заполняет магазин демо-данными: 6 категорий, 36 товаров с фото и пользователей.

**Тестовый администратор:** `admin@example.com` / `password`
